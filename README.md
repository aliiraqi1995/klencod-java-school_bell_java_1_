# جرس المدرسة — نسخة Java (أندرويد أصلي، بدون Kotlin)

مشروع Android Studio كامل بلغة Java فقط.

## المزايا
- تخصيص كل يوم من أيام الأسبوع (السبت – الجمعة) بجدول مستقل
- مفتاح تفعيل/تعطيل لكل يوم على حدة
- وقت بداية الحصة الأولى مختلف لكل يوم (تُزاح بقية الحصص تلقائياً)
- إضافة / تعديل / حذف الحصص والاستراحات
- زر تجربة الجرس + زر إعادة الضبط
- جدولة الجرس تلقائياً (AlarmManager) + إعادة الجدولة بعد إعادة تشغيل الجهاز
- حفظ البيانات محلياً بدون إنترنت

## طريقة التشغيل
1. افتح Android Studio → Open → اختر مجلد المشروع
2. انتظر Gradle Sync (يحتاج إنترنت أول مرة)
3. وصّل هاتفك (فعّل USB Debugging) أو شغّل محاكياً ثم اضغط Run ▶
4. لبناء APK: Build → Build Bundle(s)/APK(s) → Build APK(s)

## ملف الصوت
استبدل ملف الجرس الموجود في:
app/src/main/res/raw/bell.mp3
بملف صوت حقيقي (MP3) بنفس الاسم — حالياً الملف مؤقت صغير جداً.

## بنية المشروع
- MainActivity.java : الواجهة الرئيسية وتبويبات الأيام
- Period.java / DaySchedule.java : نماذج البيانات
- ScheduleStorage.java : الحفظ المحلي
- BellScheduler.java / AlarmReceiver.java : جدولة الجرس والإشعارات
- BootReceiver.java : إعادة الجدولة بعد تشغيل الجهاز
- res/layout/ : شاشات XML
